# 레지스터 설정이란

레지스터란 칩 안의 회로에 직결된 스위치 판이다. 
일반 변수와 달리 TCCR1A, ADMUX같은 이름이 붙은 레지스터는 칩을 설계할 때부터 특정 하드웨어 회로에 물리적으로 배선되어 있는 특수 주소다. 
그 레지스터의 비트 하나하나가 실제 회로 안의 스위치나 신호 선택에 직접 연결되어있어서, 그 레지스터의 값을 쓰는 순간, 데이터가 저장되는 것이 아니라 칩 내부 회로의 물리적 동작이 발생하게 된다. 
위 내용을 바탕으로, '레지스터를 설정한다'는 '칩 안에 이미 연결된 스위치들을 코드를 통해 원하는 대로 동작시키는 것'이다. 
추가로, 데이터 시트에 레지스터 표가 나오게 되는데, 이는 해당칩에 어떤 스위치가 있고, 어떤 비트에 어떤 회로가 동작되는지를 정리해 둔 표라고 볼 수 있다.  

# 레지스터 설정 예시

## 서보모터
-OCR1A: 펄스 폭(서보 각도)를 정하는 값. 이 숫자를 크게 하면 서보가 더 많이 돌고, 작게 하면 덜돈다. (예: 1500 넣으면 중앙(90도))

-TCCR1B: 타이머가 몇초마다 한 번씩 반복할 지, 클럭을 얼마나 나눠 쓸지 정하는 설정. 프로그램 시작할 때 한 번만 정해두고 건드리지 않아도 된다. (예: 분주비 8로 설정하면 20ms 주기의 PWM 생성)

## PSD센서
-ADMUX: 몇 번 핀의 전압을 잴지 고르는 설정. PSD 센서가 몇번 핀에 꽃혀있는지 맞춰 채널 번호를 넣는다. (예: 0번 채널을 쓰면 ADC0 핀 전압을 측정)

-ADCSRA: ADC기능을 켜고 얼마나 천천히 잴지 분주비를 정하는 설정. (예: 분주비 128로 설정하면 ADC 클럭이 125kHz가 되어 안정적으로 측정 가능)

## UART
-UBRR: 통신 속도를 정하는 값. PC랑 속도가 안 맞으면 서로 못 알아듣는다. (예: 9600bps로 맞추려면 103을 입력)

-UCSR1B: 송신, 수신 기능을 켜는 설정. 둘 다 켜야 보내고 받는 것이 가능하다.
